# Гулять с Даником

Мини-сайт с приглашением на прогулку по Ганноверу и Хильдесхайму.

Статический HTML/CSS/JS, публикация через GitHub Pages из main / root. Локально: `python -m http.server 4173`.

Приглашение появляется через 5,5 секунды. Форма отправляет данные на danko.penko@gmail.com через FormSubmit. Перед использованием нужно один раз активировать адрес по ссылке из письма FormSubmit. Не храните ключи или пароли в этом репозитории. При сбое есть ссылка на готовое письмо в почтовом приложении. Без выбранной даты день недели — пожелание, точная дата согласуется лично. Время — Europe/Berlin.
